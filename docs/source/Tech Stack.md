# Tech Stack (Production-Ready, Antigravity-Powered)

## Tooling Anchor: Google Antigravity

**Google Antigravity** is the development environment and agent platform. It is not merely an IDE — it is an **agent-first control center** where autonomous agents plan, execute, and verify complex end-to-end tasks[reference:3]. The engineer will use:

- **Agent Manager** to orchestrate multiple agents in parallel across workspaces[reference:4].
- **Artifacts** (task lists, implementation plans, walkthroughs, screenshots, browser recordings) to review and approve work before code changes land[reference:5][reference:6].
- **GitHub MCP integration** to let agents create commits and pull requests directly in the repository, without leaving the Antigravity environment[reference:7].
- **Firebase / Google Cloud deployment** via Antigravity's native provisioning and `gcloud` automation[reference:8][reference:9].

No external Git client, no manual deployment dashboard, and no foreign Git remote is required. The project lives in a single repository that Antigravity's agents manage end-to-end.
